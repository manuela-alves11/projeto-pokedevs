# Pokedevs

Projeto desenvolvido para praticar HTML, CSS e JavaScript por meio da criação de uma interface inspirada no universo Pokémon.

## Funcionalidades

- Listagem de personagens
- Exibição dinâmica das informações
- Layout responsivo
- Interface intuitiva

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Objetivo

Praticar manipulação do DOM, organização de código e desenvolvimento de interfaces responsivas.

## Aprendizados

Durante este projeto desenvolvi habilidades em:

- Estruturação de páginas HTML
- Estilização com CSS
- Manipulação do DOM utilizando JavaScript
- Organização de arquivos em projetos Front-end

## Melhorias futuras

- Campo de pesquisa
- Filtros por categoria
- Animações
- Dark Mode
